# Devil's advocate

Use this when the council, or a workspace file like `decision-record.md`, is settling on a proposal too easily.

1. Find the load-bearing assumption: the single claim the proposal cannot survive without.
2. Give the most concrete, plausible scenario in which that assumption is false.
3. Name the cheapest test that would tell the council which world it is in.

Say it in at most 2 sentences: the assumption and its failure scenario first, the cheap test second.
